# Cheery Chic Online Shop — catatan untuk agent

- Laravel 13, PHP 8.3+, MySQL (test pakai SQLite in-memory), Tailwind v4 + Alpine.js, Blade (tanpa Livewire/Inertia).
- Bahasa UI: Indonesia. Locale `id`, timezone `Asia/Jakarta`.
- Peran user: `App\Enums\UserRole` (admin/customer). Route dilindungi middleware `role:admin` / `role:customer`.
- Kolom `role` dan `is_active` sengaja tidak mass-assignable; ubah dengan `forceFill`.
- Pembayaran & ongkir lewat interface `App\Contracts\PaymentGateway` dan `App\Contracts\ShippingProvider`; driver dipilih di `AppServiceProvider` dari `config/shop.php`.
- Perubahan status pesanan lewat `App\Services\Orders\OrderService` (aturan transisi ada di `OrderStatus::nextStatuses()`).
- Brand Cheery Chic (daster wanita: daster, dress, one set rayon premium; motto `shop.motto` "Cantik di Rumah, Ceria Setiap Hari", hashtag #CeriaDiRumah): logo resmi = `<x-logo>` (path SVG hasil trace logo asli: monogram emas "CC" + tulisan "CheeryChic" serif miring). Varian: `full` (berdampingan, header), `stacked` (seperti logo asli, footer), `mark` (monogram), `word`; prop `tagline`, `dark`, `mono`. Aset di `public/images/brand` (`cheerychic-logo-original.jpg` = file asli, SVG/ikon/OG dirender dari path yang sama). Monogram satu warna yang ringan: `.logo-mask` (mask CSS, warna = `bg-*`). Warna di `resources/css/app.css`: `ink` (#33241C kakao, teks/tombol utama/footer), `sand-*` (krem susu, latar foto), `brand-*` emas logo (`brand-400` #D6AE32; tombol beli `.btn-brand`, peringkat, ornamen; teks emas di latar putih pakai `brand-600/700`), `blush-*` merah muda motif bunga (latar seksi ceria, label Baru), `sage-*` hijau daun (hemat), `accent-*` koral HANYA diskon/Promo, `navy-*` = kakao pelengkap. Font self-hosted `@fontsource`: Plus Jakarta Sans (isi), Playfair Display (`font-display`/`font-logo`, judul `.display`/`.section-title`; `<em>` di judul = miring emas). Judul seksi beranda dari admin: `*kata*` → miring emas lewat `Storefront::emphasize()` (hero: kata terakhir otomatis). Ornamen: `.kicker`/`.flower-dot` (bunga 5 kelopak, mask `--flower-mask`), `.ornament-bg` (bunga emas di latar gelap) / `.ornament-bg-light` (daisy di krem/blush), `.scallop`/`.scallop-up` (tepi renda/rempel, warna lewat `text-*`), `.arch` (bentuk "daun" hero/ubin), `.arch-soft` (foto produk). Ilustrasi hero bawaan = rak daster (`public/images/hero/hero-default*.svg`); seeder memasang foto hero contoh `images/demo/hero-cheerychic.webp`. Ikon kategori/koleksi: `<x-category-icon for="...">` (dress, set, busui, kaftan, pajama, jumbo, batik, flower, kids, gift, moon, accessories, sparkles). Foto produk: URL lengkap (`ProductImage::isRemote()`), aset bawaan `images/...` di folder public (`isBundled()`, dipakai seeder: `public/images/demo/products/{slug}-{n}.webp`, foto ke-n = varian motif ke-n lewat `product_image_id`), atau file di disk public.
- Halaman error pakai `<x-error-page>`; jangan bergantung pada sesi/keranjang (404 untuk URL tanpa route dirender tanpa middleware web).
- Komponen Blade: `resources/views/components` (layout `x-layouts.shop|admin|account|auth`, `x-icon`, `x-product-card`, dll). Kelas utilitas `.btn`, `.input`, `.card`, `.badge` di `resources/css/app.css`.
- Form: pakai komponen `resources/views/components/form` (`x-form.input|money|number|phone|date|date-range|select|category-select|textarea|image-upload|file|errors|field`). Label, petunjuk, `old()` dan error sudah ditangani. Perilaku JS = directive Alpine di `resources/js/forms` (`x-searchable` Tom Select, `x-datepicker[.time]`/`x-daterange` flatpickr bahasa Indonesia, `x-money` ribuan Rupiah → terkirim angka bersih, `x-phone`); library di-import dinamis, CSS di-host lewat npm. Di dalam template Alpine pakai `x-bind:name`, bukan `:name`.
- Tooltip info di form admin: prop `tip` (penjelasan) + `tips` (array saran) di semua `x-form.*`, otomatis jadi ikon ? di samping label. Di luar komponen form pakai `<x-tip title text :tips>` (taruh di `.label-row` bersama `.label`). Hover/fokus di desktop, ketuk di HP; panel di-teleport ke body (aman di tabel/overflow). Logika = Alpine `tip` (`resources/js/components/tooltip.js`), gaya `.tip-*` di `app.css`. Field yang fungsinya tidak jelas & semua isian foto wajib diberi tip (foto: rasio, ukuran px, area aman sesuai tempat tampilnya).
- Jalankan `php artisan test` sebelum commit.
- Katalog: kategori maks 2 tingkat (`parent_id`), galeri `ProductImage` (sampul = `sort_order` terkecil, `Product::coverImage` selalu di-eager-load), varian `ProductVariant`. Produk bervarian (`has_variants`) menyimpan ringkasan harga termurah & total stok varian aktif lewat `Product::syncVariantSummary()`.
- Stok (`products.stock`, `product_variants.stock`) tidak mass-assignable. Ubah selalu lewat `App\Services\Catalog\StockService` (adjust/set) supaya terkunci & tercatat di `stock_movements`.
- Kunci keranjang di session: `"{product_id}"` atau `"{product_id}-{variant_id}"`.
- Promo: voucher lewat `App\Services\Promo\VoucherService` (cek syarat, hitung potongan, kode terpasang di session `checkout_voucher`). Kuota & batas per pelanggan dihitung dari pesanan yang tidak dibatalkan (`Voucher::redemptions()`), jadi pembatalan otomatis mengembalikan kuota. `orders.total` = subtotal − discount + shipping_cost − shipping_discount; Midtrans menerima potongan sebagai item `VOUCHER` bernilai negatif. Banner beranda: model `Banner` (scope `visible`).
- Impor/ekspor katalog: `App\Services\Catalog\Transfer` (OpenSpout, xlsx/csv). Alur: unggah → `ProductImport` (validating → ready → importing → completed) → pratinjau error per baris → commit. File > 300 baris lewat antrean (`ProcessProductImport`). Format ekspor produk = template impor. Impor produk butuh `catalog.manage`, update stok massal butuh `stock.manage`.
- Login Google pelanggan: Firebase Authentication (`x-firebase-login`, `POST /masuk/google`). Token diverifikasi `App\Services\Auth\FirebaseTokenVerifier` (sertifikat publik Google, tanpa service account), akun dicocokkan `FirebaseLoginService` lewat `users.firebase_uid` (tidak mass-assignable) / email terverifikasi. Staf tidak bisa login Google. Aktif bila `FIREBASE_API_KEY` + `FIREBASE_PROJECT_ID` terisi; setup di `docs/FIREBASE.md`.
- Beranda: hero (foto, teks, 2 tombol) & pengumuman topbar diatur di Admin › Tampilan Beranda (`Admin\StorefrontController`, disimpan lewat `StoreSettings` kunci `shop.storefront.*`, dibaca via `App\Support\Storefront`). Tanpa foto → ilustrasi `public/images/hero/hero-default*.svg`. Tab "Best Seller" (`App\Services\Storefront\BestSellers`): mode Otomatis = terjual 90 hari dari pesanan berstatus revenue (cache 30 menit), dilengkapi produk unggulan/terbaru; mode Manual = pilihan & urutan admin (`shop.storefront.best_seller_products`, nonaktif/stok habis dilewati), opsional dilengkapi otomatis; tampil sebagai korsel geser dengan nomor peringkat (prop `rank`). `<x-product-tile>` = alias `<x-product-card>` (foto di latar krem, info di bawah, tombol "+" tambah cepat di pojok foto).
- Navbar transparan: `<x-layouts.shop transparent-header>` membuat header menyatu dengan bagian pertama berlatar gelap (main ditarik ke atas setinggi header, jadi bagian itu perlu padding atas `pt-24`+), lalu jadi putih solid saat di-scroll / mega menu dibuka (atribut `data-clear`, varian `group-data-[clear]/header:`). Dipakai di beranda (bila teks hero terang); katalog berkepala terang (header biasa). Logo header pakai `adaptive`.
- Koleksi (tema, mis. Travel & Umrah, Hadiah Spesial): model `ProductCollection` (tabel `collections`, pivot `collection_product`), banyak-ke-banyak dengan produk — beda dari kategori (satu per produk). Admin `admin.collections.*` (izin `catalog.manage`), isi diatur di form koleksi atau kolom `collection_ids[]` di form produk. Katalog `?koleksi=slug` (bisa digabung `kategori`). Ubin "Pilih gaya santaimu" & rel hero "Pilih koleksimu" = `App\Services\Storefront\ActivityTiles` (sumber `shop.storefront.activities_source`: auto → koleksi `show_on_home`, cadangan kategori induk).
- Seksi beranda: urutan & tampil/sembunyi = `shop.storefront.sections` (kunci di `Storefront::SECTIONS`, partial `resources/views/shop/home/{kunci}.blade.php`), teks seksi `shop.storefront.*` dibaca via `Storefront::text()`; diatur di Admin › Tampilan Beranda › Seksi & teks (`StorefrontController::updateSections`).
- Integrasi (Admin › Integrasi, `Admin\IntegrationController`): driver & kunci Midtrans/RajaOngkir/Firebase disimpan lewat `StoreSettings` (tipe `secret` = terenkripsi APP_KEY, tidak pernah ditampilkan/di-log utuh), .env sebagai cadangan; tombol "Tes koneksi" = `IntegrationTester`. Hanya jabatan Owner (label "Superadmin") lewat izin `integrations.manage`.
- Artikel/blog: `Article` + `ArticleCategory` (publik `/artikel`, admin `admin.articles.*`, izin `articles.manage`). Simpan lewat `App\Services\Content\ArticleService` (slug unik, HTML disaring `ArticleSanitizer` / symfony html-sanitizer, produk terkait, sampul). Terjadwal = status `published` + `published_at` di masa depan (scope `published`). Editor Tiptap = Alpine `articleEditor` (gambar diunggah ke `admin.articles.images`, folder `articles/content`). Gaya isi artikel: kelas `.article-prose`. Masuk sitemap & seksi "Artikel terbaru" beranda.
- Daftar admin: pakai `App\Support\AdminList::paginate($query, $request, $default)` (+ `AdminList::sort()` untuk `?sort=kolom|-kolom`) dan `<x-admin.pagination :paginator label="..." />`, `<x-admin.sort-link column>`, `<x-admin.sort-select>`, `<x-admin.keep-query />` di form filter. Pilihan baris per halaman diingat di session per daftar. Link ke halaman lain dibungkus `@can` sesuai izin route-nya (cek jabatan Gudang/CS).
- Konfirmasi & notifikasi: jangan pakai `confirm()`/`alert()` bawaan browser. Tambah `data-confirm="..."` (+ `data-confirm-title`, `data-confirm-ok`, `data-confirm-tone="danger|primary"`) di `<form>`/tombol submit, atau `<x-confirm-delete>`; dari JS `await window.confirmDialog({...})` dan `window.toast(pesan, 'success|error|warning|info')` (`resources/js/components/dialogs.js`, markup di `components/flash.blade.php`). Flash session `success|error|warning|info|status` otomatis jadi toast.
- Sidebar admin bisa diciutkan (ikon + tooltip), status di cookie `admin_sidebar` (tidak dienkripsi, dibaca Blade supaya tidak berkedip).
- Rate limit di route: selalu beri nama, mis. `throttle:20,1,voucher`. Tanpa nama, semua `throttle:N,M` berbagi satu penghitung per user/IP sehingga route lain ikut menghabiskan kuotanya.
- Desain toko Cheery Chic: ceria, feminin, rumahan. Hero blush bermotif daisy dengan foto dalam bingkai daun + stempel motto berputar + stiker keunggulan, tepi bawah renda; pita berjalan emas (`ribbon`); kartu produk potret 3:4 (`.arch-soft`, info rata tengah, tombol "Pilih motif"/"Keranjang" emas muda, nomor peringkat emas); seksi `lookbook` (pilih model → foto tiap motif, data dari `HomeController`); "Kenapa" = pita kakao bermotif bunga emas bertepi renda. Katalog `/produk`: kepala blush + kategori foto bulat, satu panel "Filter & urutkan". Link "Promo" di navbar berwarna `accent` + titik berdenyut.
